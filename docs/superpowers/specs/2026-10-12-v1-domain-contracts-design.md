# 首版设计基线：领域与共享契约

日期：2026-10-12。状态：产品方向与本轮评审结论已获用户批准；本文定义领域语义，不是已经生成的 schema 或数据库迁移。统一入口见 [CONTINUITY](../../CONTINUITY.md)。

## D-01：实体与关系

实体划分用于解释业务，不要求每个概念单独建表。

- 用户目标：求职目标、语言、可用时间与用户调整。首版可属于本地学习者，不以账号系统为前提。
- 知识点：前置关系和观察粒度；“会集合操作”与“想到用集合消除重复查找”分别观察。
- 学习单元：组织目标、知识点、可靠资料、代表题与后续练习。
- 题目：稳定身份、来源、站点、版本与知识点多对多关联；既有 16 种模式继续分类，不能代替细粒度知识点。
- 会话：关联学习目标和题目快照，保存当前进度、状态与下次起点。首版一次练习会话围绕一道题。
- 尝试：用户当时的思路、代码或“我不会”等真实输入；归属于会话与题目快照。草稿与已提交尝试分开处理。
- 提交：一次向判题平台提交代码的事实，保存提交时快照与判题来源；不同于向教练提交尝试。
- 提示与讲解：帮助请求及实际收到、展示的内容分别有记录，关联动作、会话与适用尝试；基础资料阅读允许无尝试。
- 复习项：明确复习对象、评分记录、FSRS 状态与下次到期；不等同于一个知识点已经掌握。
- 计划：某次安排的任务、预算、推荐原因与版本；用户调整后生成可追溯的新版本。
- 模型判断：保存依据引用、模型与提示版本、适用上下文、缺失证据、用户纠正及替代关系。
- 动作与请求：关联用户意图、调用权限、执行状态与诊断事件，承担幂等和追溯。
- 备份：版本化清单及一致的数据快照，覆盖范围由 [存储规格](2026-10-12-v1-storage-integration-design.md)定义。

关系约束：一个尝试可没有正式提交，也可关联多个提交；提交只有在关联证据足够时才能绑定尝试。独立采集的提交允许暂存为待关联，不伪造尝试。所有记录有身份和来源，但计划、资料阅读等不强制绑定尝试。

## D-02：分开管理状态

采用会话、模型请求和平台提交三个状态机。理由：用户暂停时，外部判题仍可能完成；单一线性状态不能正确表达并发过程。

会话规则：

- 开始：用户选择任务；保存会话与题目快照后进入 active，保存失败不显示已开始。
- 暂停：用户主动暂停；保存草稿、位置和下次起点后进入 paused，撤销当前教练请求的有效写入资格。
- 继续：用户恢复 paused 会话，重新读取保存状态后进入 active；不自动重发请求。
- 结束：用户结束本次练习，持久化摘要后进入 ended；重复结束幂等。再练同题创建新会话并引用历史。
- 页面关闭不证明用户主动暂停或疲劳；重开时展示实际保存状态及未完成请求。

请求规则：复用当前 pending、succeeded、failed、expired、superseded、cancelled 语义。请求资格在发出前预留，结果保存时再次检查；暂停、换题、新尝试与结束均不能让旧反馈覆盖新位置。

提交规则：分别表示已采集、待判题、判题完成、结果不可用。AC、WA 等属于平台判题结果；网络失败不是 WA。已匹配的真实提交结果可归档到原会话，即使会话已暂停或结束，也不能激活会话或覆盖当前题。

界面的空闲、选题、思考、求助、复盘、安排后续是上述状态与任务的展示阶段，不强制逐个建数据库状态。

恢复点：会话快照、已保存草稿、有效尝试、请求状态与已关联提交。恢复操作只读或修正过期状态，不凭恢复动作调用模型。

## D-03：共享契约与执行权限

- 共享运行时 schema 是唯一类型来源；TypeScript 类型可直接推导。网页、侧栏和核心不得复制一套独立字段定义。
- 跨端消息必须带协议版本、动作 ID、来源身份及与该动作相符的会话/题目/尝试引用。具体字段与错误枚举在接口 RFC 中统一。
- 状态修改使用幂等键与预期版本；相同 ID、相同内容返回已知结果，相同 ID、不同内容拒绝。
- 身份、权限、版本、大小、字段、引用关系、允许状态均由程序验证。模型文本没有提升权限的能力。
- 模型只能输出允许的反馈或建议；不直接更新原始事实、FSRS 评分或工具权限。
- 每个工具明确输入、输出、允许触发者、副作用、幂等语义、超时和错误分类；首版无需通用工具插件框架。
- 非法转换、越权和非法输出应产生脱敏诊断；存储本身失败时提供内存中的错误信息，不能承诺诊断一定能落库。

## D-04：事实、判断与删除

原始尝试、实际帮助和平台结果不被模型覆写。用户更正采用关联的更正记录；真正删除按隐私策略清理原始内容及派生记录。append-only 约束不能阻止用户删除。

判断保存证据和未知项，不把未经校准的模型自报数字当成可靠概率。撤销建议只影响仍可撤销的本地安排；已展示讲解、已发生调用和费用不能回滚。

## 与现有实现的差异

当前 [教练核心契约](2026-10-11-coach-core-design.md)只有 active/ended，禁止完整答案，且要求先有尝试才能提示。新设计的 paused、讲解权限及无代码求助需要显式变更契约与测试；不能伪造尝试或绕过等级校验。用户实际说“我不会”可以作为真实观察保存。

当前表结构、函数签名和备份范围不因本设计文档自动改变。实施前必须提交共享 schema RFC、兼容性说明和迁移方案。

## 契约验收入口

- AC-01：身份、来源和引用关系可追溯，缺失关联不推测填充。
- AC-02：状态机、权限、幂等及跨端版本校验。
- AC-03：暂停、结束、换题和迟到结果不污染当前会话。

详细证据要求与依赖见 [验收规格](2026-10-12-v1-acceptance-release-design.md)。
